## 1. 초과근무 수당 계산의 복잡성

대한민국 근로기준법 제56조(연장·야간 및 휴일 근로)에 따르면, 사업주는 법정 기준 근로시간을 초과하여 근로한 근로자에게 법정 가산 수당을 지급해야 합니다. 그러나 실제 계산 과정에서는:
- 연장근로와 야간근로(22:00 ~ 06:00)가 중복되는 경우
- 휴일근로가 8시간을 초과하면서 동시에 야간근로에 해당하는 경우
- 월 통상임금과 209시간(주 40시간제 기준 월 소정근로시간) 간의 시간급 환산

등 다양한 법적 할증 요율이 중첩되어 근로자와 사업주 모두 계산에 혼선을 겪기 쉽습니다. **Korea OT** 계산기는 이러한 복잡한 계산을 한 번의 입력으로 투명하게 분석하도록 구현되었습니다.

---

## 2. 법정 가산 수당 요율 체계

근로기준법에 따른 주요 할증 요율은 다음과 같습니다:

| 근로 구분 | 적용 요율 | 상세 기준 |
| :--- | :--- | :--- |
| **연장 근로** | **1.5배 (150%)** | 1일 8시간 또는 1주 40시간 초과 근로 |
| **야간 근로** | **0.5배 가산 (+50%)** | 오후 10시(22:00)부터 다음 날 오전 6시까지의 근로 |
| **휴일 근로 (8시간 이내)** | **1.5배 (150%)** | 주휴일, 관공서 공휴일 등 법정 휴일 근로 |
| **휴일 근로 (8시간 초과)** | **2.0배 (200%)** | 휴일에 8시간을 넘겨 계속 근로한 시간 |

### 중복 할증 예시
휴일에 출근하여 밤 11시까지 근무했다면(휴일 8시간 초과 + 야간 근로 겹침):
- 기본 100% + 휴일 초과 100% + 야간 가산 50% = **총 250% (2.5배)** 의 임금이 지급되어야 합니다.

## 3. 계산 엔진 알고리즘 설계

시간대별 타임라인을 30분 단위 슬롯으로 분할하여 각 슬롯의 성격을 판정하는 타임라인 슬라이싱(Timeline Slicing) 기법을 채택했습니다.

```typescript
interface WorkSlot {
  startTime: string;
  endTime: string;
  isOvertime: boolean;
  isNight: boolean;
  isHoliday: boolean;
}

function calculateSlotMultiplier(slot: WorkSlot): number {
  let rate = 1.0; // 기본 근로
  
  if (slot.isOvertime) rate += 0.5; // 연장 가산
  if (slot.isNight) rate += 0.5;    // 야간 가산
  if (slot.isHoliday) {
    rate += slot.isOvertime ? 1.0 : 0.5; // 휴일 8시간 초과시 100%, 이내시 50%
  }
  
  return rate;
}
```

## 4. 실무적 편의 기능과 검증

1. **시급 ↔ 월 통상임금 자동 변환**: 주 40시간 기본 근무제 기준인 `209시간` 공식을 적용하여, 사용자가 월급만 입력해도 통상시급을 즉각 도출합니다.
2. **실시간 Breakdown 차트**: 총 수당 금액만 표시하는 것이 아니라 연장, 야간, 휴일 수당 각각의 계산 근거를 항목별로 투명하게 보여줍니다.
3. **오프라인 동작**: 서버 전송 없이 100% 브라우저 클라이언트에서만 연산되므로 개인 급여 정보의 유출 위험이 전혀 없습니다.
